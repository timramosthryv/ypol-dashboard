# YPOL Content Dashboard

Live dashboard of YPOL Content Submission Form entries for the Thryv Customer Success Organization.

**Live site:** https://timramosthryv.github.io/ypol-dashboard/

**Data flow:** Jotform (YPOL Content Submission Form, 263214700724045) > Google Sheets integration > this page, which reads the sheet on load.

The Google Sheet must stay shared as "Anyone with the link, Viewer" for the dashboard to load. Uploaded files (Business Logo, Photo Gallery) are kept in the sheet but are not shown on the dashboard.
